# Brand Design System & Color Theme Rules

## Mandatory Directive
All AI agents modifying or generating frontend views, admin panels, editors, components, and CSS must strictly follow the site's brand design palette. **DO NOT USE BLUE COLORS** under any circumstances.

## Brand Color Palette
- **Primary Brand Green:** `#075603`
- **Primary Dark (Hover/Active):** `#053b02`
- **Primary Light (Badge / Tab Background):** `#eaf5e9`
- **Accent Green (Glows & Highlights):** `#068200`
- **Focus Ring Glow:** `rgba(6, 130, 0, 0.15)`
- **Sidebar Background:** `#0d1512`
- **Sidebar Active:** `#075603`
- **Text Primary:** `#0f172a`
- **Text Muted:** `#64748b`

## Forbidden Colors
- Avoid `#2271b1`, `#0284c7`, `#3b82f6`, `#2563eb`, `#1d4ed8`, `#e0f2fe`, `#f0f9ff`, `#eff6ff` or any generic blue variations.

## Typography
- Primary Font Stack: `'Kalpurush', 'payasti_uni', 'Hind Siliguri', sans-serif`
